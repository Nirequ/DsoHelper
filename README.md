# DSO Helper

Небольшой помощник для Drakensang Online 

## Настройка

1. Откройте инвентарь в игре.
2. Нажмите «Выбрать слот» — появится квадрат. Перетащите его на нужный
   слот, отпустите и подождите 3 секунды. Позиция сохранится автоматически.
3. В разделе «Вкладка инвентаря» выберите нужную вкладку ([1]…[8] или prem),
   нажмите «Указать позицию» и поставьте квадрат на её заголовок. Позиция
   запоминается отдельно для каждой вкладки. После открытия инвентаря макрос
   кликнет по выбранной вкладке, чтобы плащ всегда оказывался в одной и той же
   ячейке (как в DrakenHub). Переключатель «Переключать» отключает этот шаг.
4. Задержки по умолчанию — 30 мс на каждое действие, как в DrakenHub. Увеличивайте
   только если какое-то действие не успевает сработать.
5. Запускайте по хоткею (по умолчанию `F8`) или кнопкой «Выполнить Fast Mount».

Опция «Вызывать маунта с закрытым инвентарём» экспериментальная: DrakenHub
вызывает маунта с открытым инвентарём, поэтому по умолчанию она выключена.

Настройки хранятся в `config.json` рядом с exe.
