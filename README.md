# DSO Helper

Небольшой помощник для Drakensang Online 

## Настройка

1. Откройте инвентарь в игре.
2. Нажмите «Выбрать слот» — окно скроется, появится квадрат, который сам
   следует за мышью. Кликните левой кнопкой по нужному слоту — координаты
   сохранятся сразу (Esc отменяет выбор).
3. В разделе «Вкладка инвентаря» выберите нужную вкладку ([1]…[8] или prem).
   Нажмите «Указать вкладку 1» и кликните по заголовку первой вкладки,
   затем «Указать вкладку 2» и кликните по второй — расстояние между ними станет
   шагом. Остальные вкладки макрос рассчитает сам
4. Запускайте по хоткею (по умолчанию `F8`) или кнопкой «Выполнить Fast Mount».
