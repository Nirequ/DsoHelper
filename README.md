# DSO Helper

Небольшой помощник для Drakensang Online на C# + Avalonia.

## Fast Mount

Одна кнопка (или глобальный хоткей) выполняет всю цепочку:

1. открывает инвентарь;
2. двойным левым кликом меняет плащ в выбранном слоте на плащ с быстрым маунтом;
3. вызывает маунта;
4. двойным кликом возвращает старый плащ в тот же слот;
5. закрывает инвентарь.

После завершения курсор возвращается туда, где он был до запуска.
Позиция слота хранится относительно клиентской области окна игры, поэтому смена
разрешения или переход из полноэкранного режима в оконный не требует повторного
выбора слота.

## Запуск

Нужен .NET 10 SDK (для сборки) или .NET 10 Desktop Runtime (для готового exe).

```powershell
dotnet run
```

Сборка:

```powershell
dotnet build -c Release
```

## Один exe для друга

Собрать автономный одиночный exe (не требует установленного .NET):

```powershell
dotnet publish -p:PublishProfile=win-x64
```

Готовый файл — `dist\win-x64\DsoHelper.exe` (~48 МБ). Его достаточно передать:
настройки (`config.json`) создадутся рядом при первом запуске.

> Сборка под Windows x64. При первом запуске SmartScreen может предупредить
> о неизвестном издателе — «Подробнее» → «Выполнить в любом случае».

## Настройка

1. Откройте инвентарь в игре.
2. Нажмите «Выбрать слот» — появится квадрат. Перетащите его на нужный
   слот, отпустите и подождите 3 секунды. Позиция сохранится автоматически.
3. Клавиши не нужно набирать вручную: кликните по полю («Хоткей», «Инвентарь»
   или «Кнопка маунта») и просто нажмите нужную клавишу — название подставится
   само (`Space`, `F1`, `Left`, `=` и т.д.). Для хоткея можно зажать
   модификаторы: `Ctrl+F8`, `Alt+1`. `Esc` отменяет ввод.
4. При необходимости поправьте задержки в миллисекундах.
5. Запускайте по хоткею (по умолчанию `F8`) или кнопкой «Выполнить Fast Mount».

Настройки хранятся в `config.json` рядом с exe.

## Трей

При сворачивании окно убирается в системный трей. Иконка в трее остаётся
доступной: клик по ней или пункт «Открыть DSO Helper» возвращает окно,
«Выход» завершает приложение. Хоткей продолжает работать, даже когда окно
свёрнуто в трей.

> Хоткей срабатывает только когда активна игра. Вне окна Drakensang клавиша
> работает как обычно (например, `Space` просто печатает пробел — вводить
> текст с ним не мешает). Кнопка «Выполнить» сама пытается переключиться в
> окно Drakensang, а если не нашла его — даёт 3 секунды, чтобы переключиться
> вручную.
