# DSO Helper

Утилита для Drakensang Online: быстрый маунт, проверка инвентаря и автопродажа неопознанных
предметов. Один exe, устанавливать ничего не нужно.

## Возможности

- **Fast Mount (F8)** — надевает плащ с быстрым маунтом, вызывает маунта и возвращает старый плащ.
- **Проверка инвентаря** — показывает, сколько ячеек занято, какие редкости лежат, находит «?».
- **Автопродажа (F9)** — продаёт неопознанные предметы выбранных качеств по нужным вкладкам.
- Хоткеи настраиваются и срабатывают только когда активно окно игры.

## Как начать

1. Скачайте `DsoHelper.exe` со страницы [Releases](https://github.com/Nirequ/DsoHelper/releases/latest)
   и запустите. Положите в папку, куда у программы есть доступ на запись.
2. **Fast Mount:** нажмите «Выбрать слот» и кликните по ячейке с плащом, проверьте клавиши
   инвентаря и маунта. Если плащ на другой вкладке — включите переключение и укажите вкладку.
3. **Инвентарь:** укажите центр левой верхней ячейки и правой нижней — остальные вычислятся сами.
4. **Автопродажа:** отметьте качества, которые нужно продавать, и вкладки.

## Что важно знать

- Игра должна быть в оконном режиме или в «полноэкранном без рамки».
- Если старый плащ иногда остаётся в сумке — увеличьте «Паузу после вызова маунта»:
  пока идёт призыв, игра не принимает клики по инвентарю.
- Настройки хранятся рядом с exe в `config.json`; удалите файл, чтобы сбросить калибровку.
- Программа не подписана, поэтому SmartScreen может предупредить. SHA-256 сборки указан
  в описании релиза — при желании сверьте: `Get-FileHash .\DsoHelper.exe -Algorithm SHA256`.
- Автоматизация игры может нарушать её правила — используйте на свой риск.
