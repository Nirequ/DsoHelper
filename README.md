# DSO Helper

Небольшой помощник для Drakensang Online 

## Настройка

1. Откройте инвентарь в игре.
2. Нажмите «Выбрать слот» — появится квадрат. Перетащите его на нужный
   слот, отпустите и подождите 3 секунды. Позиция сохранится автоматически.
3. При необходимости поправьте задержки (мс): «После открытия инвентаря», «После
   смены плаща», «После вызова маунта», «После возврата плаща». Ключевая — «После
   смены плаща»: пауза, за которую игра успевает применить новый плащ до нажатия
   клавиши маунта. Если маунт вызывается медленно — увеличьте её.
4. Запускайте по хоткею (по умолчанию `F8`) или кнопкой «Выполнить Fast Mount».

Настройки хранятся в `config.json` рядом с exe.
