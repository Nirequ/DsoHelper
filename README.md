# DSO Helper

Небольшой помощник для Drakensang Online 

## Настройка

1. Откройте инвентарь в игре.
2. На вкладке «FAST MOUNT» нажмите «Выбрать слот» — окно скроется, появится
   квадрат, который сам следует за мышью. Кликните левой кнопкой по нужному
   слоту — координаты сохранятся сразу (Esc отменяет выбор).
3. В разделе «Вкладка инвентаря» выберите нужную вкладку ([1]…[8] или prem).
   Нажмите «Указать вкладку 1» и кликните по заголовку первой вкладки,
   затем «Указать вкладку 2» и кликните по второй — расстояние между ними станет
   шагом. Остальные вкладки макрос рассчитает сам
4. Запускайте по хоткею (по умолчанию `F8`) или кнопкой «Выполнить Fast Mount».

## Авто-продажа

Раздел открывается вкладкой «АВТО-ПРОДАЖА» вверху окна.

1. Откройте у торговца окно «Купить и продать»: продажа идёт правым кликом
   по предметам в сумке.
2. Нажмите «Ячейка 1» и кликните по левой верхней ячейке сумки, затем «Шаг»
   и кликните по соседней ячейке справа.
3. Укажите число столбцов и строк области.
4. В разделе «Редкость» отметьте, какие предметы продавать. По умолчанию
   продаются обычные и улучшенные (серые и синие); легендарные, уникальные
   и необычные остаются. Фильтр можно выключить — тогда продаётся всё.
5. Нажмите «Проверить область…» — окно скроется, приложение сделает снимок
   игры и покажет сетку. Рамка каждой ячейки окрашена в распознанную редкость:
   сплошная — предмет будет продан, пунктирная — пропущен по редкости.
   Кликните по продаваемой ячейке, чтобы исключить её вручную, и нажмите
   «Сохранить».
6. Продажа: хоткей `F9` (когда активна игра) или кнопка «Продать сейчас».

Редкость определяется по цвету рамки предмета на снимке экрана. Если рамка
не распознана, предмет **не продаётся** — так макрос не продаст ценное
случайно. Если на снимке много ячеек «не распознано», выключите фильтр
редкости или проверьте калибровку области.

Макрос только кликает правой кнопкой по включённым ячейкам: он не открывает
и не закрывает окна, поэтому окно торговца и сумка должны быть открыты заранее.
